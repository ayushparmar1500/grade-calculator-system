Student Grade Management System
A simple Python program for managing student names, marks, grades, and class statistics.
Features
Add a new student
Store student marks
View all students
Calculate student grades
Show total number of students
Calculate average class marks
Exit the program

Requirements
Python 3.x
No external libraries are required.
How to Run
Save the Python code as student_grade.py.
Open Command Prompt or Terminal in the same folder.
Run:
python student_grade.py
